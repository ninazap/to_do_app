## Использованные технологии и инструменты
Python — язык программирования.\
FastAPI — фреймворк.\
Pydantic — модуль для валидации данных и работы с моделями.\
SQLAlchemy — ORM для работы с базой данных.\
Docker — платформа для контейнеризации приложений.\
Docker Compose — инструмент для управления многоконтейнерными приложениями.\
Uvicorn — ASGI сервер для запуска приложения FastAPI.\
Alembic — инструмент для управления миграциями базы данных.

Кроме того, в процессе работы возник инцидент: после моего коммита моделей ввиду сбоя модель Task отсутствовала, Михаил Марков написал её самостоятельно, а я внесла коррективы в соответствии с наработками.
