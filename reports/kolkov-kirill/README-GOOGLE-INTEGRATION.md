## 📊 Выполненные задачи

### 🔐 Задача 1: Настройка OAuth 2.0 авторизации
**Статус:** ✅ Завершено  
**Сложность:** Высокая

| Этап | Решение | Результат |
|------|---------|-----------|
| Настройка Google Cloud Console | Создан проект, включен Tasks API, настроены OAuth credentials | Получены `client_id` и `client_secret` |
| Реализация OAuth flow | Использован `google-auth-oauthlib`, настроены параметры `prompt=consent`, `access_type=offline` | Успешная авторизация с получением refresh token |
| Обработка callback | Реализован эндпоинт `/auth/callback` с валидацией state | Безопасный обмен code на токены |
| Решение проблем | Исправлены ошибки 400/403 через корректировку параметров запроса | Стабильная работа авторизации |

**Ключевой код:**
```python
# Генерация URL для авторизации
auth_url, _ = self.flow.authorization_url(
    access_type='offline',
    include_granted_scopes=True,
    state=state,
    prompt='consent'  # Гарантированное получение refresh token
)
```

**Логика синхронизации:**
```
┌─────────────────────────────────────────────────────┐
│                Процесс синхронизации                 │

│ 1. 📥 Загрузка задач из Google Tasks                 │
```

### 🐛 Задача 5: Отладка и решение проблем
**Статус:** ✅ Завершено  
**Сложность:** Средняя

| Проблема | Причина | Решение |
|----------|---------|---------|
| Ошибка 403: access_denied | Приложение не прошло проверку Google | Добавление тестовых пользователей в OAuth consent screen |
| Ошибка 400: invalid_request | Неправильные параметры OAuth | Корректировка параметров `prompt` и `include_granted_scopes` |
| Отсутствие таблицы БД | Миграция не применилась | Создание фиксирующей миграции и ручное создание таблицы |
| Токен без refresh_token | Пропущен параметр `prompt='consent'` | Принудительный запрос согласия пользователя |

## 🚀 Как запустить проект

1. **Настройка Google Cloud Console:**
```bash
# 1. Создать проект в Google Cloud Console
# 2. Включить Google Tasks API
# 3. Создать OAuth 2.0 credentials
# 4. Добавить redirect URI: http://localhost:8000/tasks/external-tasks/google/auth/callback
# 5. Добавить тестовых пользователей
```

2. **Настройка окружения:**
```bash
# Копировать credentials.json в корень проекта
# Настроить .env файл
GOOGLE_CLIENT_ID=ваш_client_id
GOOGLE_CLIENT_SECRET=ваш_client_secret
GOOGLE_REDIRECT_URI=http://localhost:8000/tasks/external-tasks/google/auth/callback
```

3. **Запуск:**
```bash
# Установка зависимостей
poetry install

# Применение миграций
poetry run alembic upgrade head

# Запуск приложения
poetry run uvicorn app.main:app --reload
```
